# Primeri Korišćenja 2.17 - Access Control

## 1. Handler sa Obaveznom Autentifikacijom

```go
package handlers

import (
	"net/http"
	"github.com/gin-gonic/gin"
	"music-backend/internal/middleware"
	"music-backend/internal/security"
)

func (h *MyHandler) GetUserProfile(c *gin.Context) {
	// Korisnik je već autentifikovan (pošto je middleware to proverio)
	userID := middleware.ExtractUserID(c)
	userRole := middleware.ExtractUserRole(c)
	userEmail := middleware.ExtractUserEmail(c)
	
	c.JSON(http.StatusOK, gin.H{
		"user_id": userID,
		"role":    userRole,
		"email":   userEmail,
	})
}
```

## 2. Rutiranje sa Zahtevom za Ulogu

```go
func (h *AuthHandler) RegisterRoutes(r *gin.Engine) {
	// Javne rute
	r.POST("/register", h.Register)
	r.POST("/login", h.Login)
	
	// Zaštićene rute - samo autentifikovani korisnici
	protected := r.Group("/api", middleware.AuthMiddleware(h.tokenManager))
	{
		protected.GET("/profile", h.GetUserProfile)
		protected.POST("/password/change", h.ChangePassword)
		protected.GET("/notifications", h.GetNotifications)
	}
	
	// Admin rute - samo administratori
	admin := r.Group("/admin", 
		middleware.AuthMiddleware(h.tokenManager), 
		middleware.RequireRole(security.RoleAdmin))
	{
		admin.POST("/users/:id/role", h.UpdateUserRole)
		admin.DELETE("/artists", h.DeleteArtist)
		admin.POST("/songs", h.CreateSong)
	}
}
```

## 3. Handler sa Provером Dozvole

```go
func (h *ContentHandler) DeleteSong(c *gin.Context) {
	// Middleware već garantuje da je korisnik admin
	userID := middleware.ExtractUserID(c)
	songID := c.Param("id")
	
	if err := h.service.DeleteSong(songID); err != nil {
		c.JSON(http.StatusInternalServerError, gin.H{"error": err.Error()})
		return
	}
	
	c.JSON(http.StatusOK, gin.H{"message": "pesma obrisana"})
}
```

## 4. Opcionalna Autentifikacija

```go
func (h *ContentHandler) GetArtists(c *gin.Context) {
	// Ako je korisnik autentifikovan, može dobiti preporuke
	userID := middleware.ExtractUserID(c)
	userRole := middleware.ExtractUserRole(c)
	
	if security.IsAuthenticated(userRole) && userID != "" {
		// Vrati preporuke za ovog korisnika
		c.JSON(http.StatusOK, gin.H{
			"artists": h.service.GetRecommendedArtists(userID),
		})
	} else {
		// Vrati samo popularne umetnike
		c.JSON(http.StatusOK, gin.H{
			"artists": h.service.GetPopularArtists(),
		})
	}
}
```

## 5. Dinamička Provera Dozvole

```go
func (h *SubscriptionsHandler) DeleteSubscription(c *gin.Context) {
	userID := middleware.ExtractUserID(c)
	subscriptionID := c.Param("id")
	
	// Proveri da li korisniku pripada ova pretplata
	subscription, err := h.service.GetSubscription(subscriptionID)
	if err != nil {
		c.JSON(http.StatusNotFound, gin.H{"error": "pretplata ne postoji"})
		return
	}
	
	if subscription.UserID != userID {
		c.JSON(http.StatusForbidden, gin.H{"error": "nemaš dozvolu za ovu akciju"})
		return
	}
	
	if err := h.service.DeleteSubscription(subscriptionID); err != nil {
		c.JSON(http.StatusInternalServerError, gin.H{"error": err.Error()})
		return
	}
	
	c.JSON(http.StatusOK, gin.H{"message": "pretplata obrisana"})
}
```

## 6. Različite Dozvole za Različite Akcije

```go
// Svako može da čita
r.GET("/songs", middleware.OptionalAuth(tokenManager), h.GetSongs)

// Samo prijavljeni mogu da ocene
r.POST("/songs/:id/rate", 
	middleware.AuthMiddleware(tokenManager),
	middleware.RequireRole(security.RoleRegularUser),

r.POST("/songs", 
	middleware.AuthMiddleware(tokenManager),
	middleware.RequireRole(security.RoleAdmin),
	h.CreateSong)
```

## Primer Kompletan API Flow

```
1. REGISTRACIJA
   POST /register
   → Vraća verification token
   
2. POTVRDA
   POST /register/confirm
   → Nalog je potvrđen, uloga je RK
   
3. PRIJAVA
   POST /login → OTP
   POST /login/verify → JWT token
   
4. KORIŠĆENJE API-JA
   GET /api/profile → Zahteva Authorization header
   
5. ADMIN AKCIJA
   POST /admin/users/{id}/role → Zahteva RoleAdmin
   
6. ODJAVA
   Token se uništava na klijentskoj strani
   (Backend može održavati token blacklist ako je potrebno)
```

## Merenje Bezbednosti

### Provere koje se vrše:

1. **Token Existence** - Svaki zahtev mora imati valid token
2. **Token Validity** - Token mora biti ispravno potpisano
3. **Token Expiration** - Token ne sme biti istekao
4. **Role Check** - Korisnik mora imati odgovarajuću ulogu
5. **Data Ownership** - Korisnik može pristupiti samo svojim podacima

### Bezbednosni Hederi

Klijent mora koristiti:
